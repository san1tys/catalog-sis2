# Измерения SIS 2

Фактический запуск 2026-10-30T19:00:59Z. Последовательный microbenchmark: один запрос в полёте, прогретые соединения, без повторов и сжатия. Порядок протоколов меняется между повторами.

Клиент: go1.25.1, darwin/arm64, GOMAXPROCS=8. Прогрев 100, измерений 1000 на группу, повторов 3, timeout 80ms. Размер каталога задаётся сервером (`-products`, по умолчанию 2000); benchmark его не меняет.

Квантили объединяют все измеренные попытки всех повторов, включая ошибки и таймауты. Метод nearest rank. Средний размер тела считается только для успешных ответов: фактическая длина JSON body и `proto.Size` полученного protobuf-сообщения. Заголовки HTTP, фреймы HTTP/2/gRPC, TCP/IP и TLS сюда не входят. Дополнительный вызов `proto.Size` входит в измеряемый gRPC-код; это небольшая измерительная накладная стоимость.

Это сравнение реализаций протоколов на данном стенде, а не нагрузочный тест или доказательство SLO из SIS #1. CPU и сеть клиента, сервера и устройства влияют на результаты. Между повторными запусками значения могут меняться. `raw.csv` содержит каждую попытку, `summary.csv` — каждый повтор и общий итог, `environment.json` — параметры. Команда заменяет файлы, поэтому для сохранения предыдущего запуска выбирайте другой `-out`.
